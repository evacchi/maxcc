# Chapter 3: expressions and loads

Split in two runnable steps.

## 3a. Expressions: global iota

```
kernel giota(out: *u32) {
    out[block_idx.x * block_dim.x + thread_idx.x] = block_idx.x * block_dim.x + thread_idx.x;
}
```

Done when `./run giota.ptx giota 1 32 2` prints `0 1 ... 63`, and
chapter 1-2 examples still pass.

### Pipeline

```
L0 --flatten--> L0-flat --address--> L1 --select--> L-ptx --emit--> .ptx
     (new)                (input: flat)   (add, mul.lo, %ctaid, %ntid)
```

- L0 (`ast.rs`): `Expr = Int | Special | Bin { op, lhs, rhs }`.
  `Special = ThreadIdxX | BlockIdxX | BlockDimX`, `BinOp = Add | Mul`.
  `+` and `*` wrap on overflow, as in PTX.
- L0-flat (`flat.rs`): `Stmt = Bin { dst: Temp, op, lhs: Atom, rhs: Atom }
  | Store { ptr, index: Atom, value: Atom }`. `Atom = Int | Special | Temp`.

Inspect: `cargo run -- --flatten file.k`.

### Read first

PTX ISA:
- Special Registers: `%ctaid`, `%ntid`.
- Integer Arithmetic: `add`, `mul.lo`, `mad`.

### Tasks

2. `address.rs`: consume L0-flat. L1 gains temps and `Bin`.
   Remove the two `todo!` arms.
3. `select.rs`: `Bin` -> `add.u32` / `mul.lo.u32`; temps -> registers;
   `%ctaid.x`, `%ntid.x`.
4. GPU: `examples/giota.k`, 2 blocks of 32.
