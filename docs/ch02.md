# Chapter 2: thread identity, indexing

```
kernel iota(out: *u32) {
    out[thread_idx.x] = thread_idx.x;
}
```

Done when 32 threads print `param 0 = 0 1 2 ... 31`, and chapter 1
examples still pass.

## Pipeline

```
L0 --address--> L1 --select--> L-ptx --emit--> .ptx
     (new)           (rewrite for L1)
```

- L0 (`ast.rs`): `Store { ptr, index: Expr, value: Expr }`,
  `Expr = Int(u32) | ThreadIdxX`. `*p = e` parses as `p[0] = e`.
- L1 (`l1.rs`): names resolved, element types gone. Byte addresses only:
  `Base { param, offset }` or `Scaled { param, index, scale }`.
- New PTX IR: `Operand::Sreg(Sreg::TidX)`, `Inst::MulWide`, `Inst::Add`,
  `Addr::Offset(reg, bytes)`.

Inspect: `cargo run -- --address examples/iota.k`.

## Read first

PTX ISA:
- Special Registers: `%tid`, `%ntid`, `%ctaid`.
- Integer Arithmetic: `mul` (`.lo`, `.hi`, `.wide`), `add`.
- Addresses as Operands: `[reg+imm]`.

## Experiments

- Race: `*out = thread_idx.x;` with 32 threads. Which value wins? Every run?

  Finding (A100, `experiments/race.k`): stable across runs, depends on launch shape.

  | threads | 32 | 64 | 96 | 128 | 160 | 1024 |
  |---|---|---|---|---|---|---|
  | `out[0]` | 0 | 32 | 64 | 96 | 0 | 96 |

  Lane 0 wins within a warp. A 4-scheduler model fits up to 4 warps, fails at 5.
  Unspecified is not random, and not predictable from the PTX.
- `mul.wide.u32` vs `cvt.u64.u32` + `mul.lo.u64`: compare SASS.
- Two uses of `thread_idx.x` emit two `mov`s. How many survive in SASS?

  Finding: one `S2R`, its register reused for index and value.
  `ld.param` + `cvta` + `mul.wide` + `add` become one
  `IMAD.WIDE.U32 R2, R5, R2, c[0x0][0x160]`: the param is the addend,
  read straight from the constant bank. The scale 4 costs a `MOV R2, 0x4`
  (no immediate when the addend is a constant-bank operand).
- Run `iota` with 1025 threads. What fails, and where?

  Finding: JIT succeeds; `cuLaunchKernel` returns `CUDA_ERROR_INVALID_VALUE`.
  Block size is a launch argument, checked against the device's
  `MAX_THREADS_PER_BLOCK` (1024). All or nothing: no thread runs.
- Change the runner to launch 2 blocks of 32. What does `iota` write, and why?
  (Sets up chapter 3.)

  Finding: slots 0..31 = 0..31, slots 32..63 = 0. Both blocks wrote 0..31:
  `%tid.x` restarts per block, and the language cannot name the block.
