# Chapter 2: thread identity, indexing

```
kernel iota(out: *u32) {
    out[thread_idx.x] = thread_idx.x;
}
```

Done when 32 threads print `param 0 = 0 1 2 ... 31`, and chapter 1
examples still pass.

## Pipeline

```
L0 --address--> L1 --select--> L-ptx --emit--> .ptx
     (new)           (rewrite for L1)
```

- L0 (`ast.rs`): `Store { ptr, index: Expr, value: Expr }`,
  `Expr = Int(u32) | ThreadIdxX`. `*p = e` parses as `p[0] = e`.
- L1 (`l1.rs`): names resolved, element types gone. Byte addresses only:
  `Base { param, offset }` or `Scaled { param, index, scale }`.
- New PTX IR: `Operand::Sreg(Sreg::TidX)`, `Inst::MulWide`, `Inst::Add`,
  `Addr::Offset(reg, bytes)`.

Inspect: `cargo run -- --address examples/iota.k`.

## Read first

PTX ISA:
- Special Registers: `%tid`, `%ntid`, `%ctaid`.
- Integer Arithmetic: `mul` (`.lo`, `.hi`, `.wide`), `add`.
- Addresses as Operands: `[reg+imm]`.
